## What is good and should be kept

- **Run loop isolation.** A synchronous, non-observable `turn` guard, plus an `isCurrent(turn)` check after every await. A stale transport or tool cannot write into a newer turn. `stop()` ends the turn even when a tool or transport ignores the signal. Confirmed.
- **History integrity.** `settleOpenParts` ensures every tool call has a result. Confirmed: stopping mid-tool and then sending again produces a valid Anthropic body, with the `tool_result` (`is_error`) ahead of the new user text in one user turn.
- **Restore path.** Approving an `approval-requested` call after `loadMessages` resumes correctly and encodes a valid request. Confirmed. Keep it, and fix M4 next to it.
- **The reducer.** It returns immutable messages and keeps unchanged parts by identity, as the spec checks. It parses partial tool JSON once per batch. It tolerates chunk forms and unknown events.
- **Transport aborts.** Each transport has its own `AbortController` on the native fetch, plus `abortable()` racing pending reads. Breaking out of iteration closes the connection. `spyFetchSignals` tests both.
- **`SseParser`.** It follows the WHATWG spec, including CR, LF and CRLF handled across chunks. The test splits the input at every byte offset.
- **Codecs.** The codec and transport split matches D5. The Anthropic round-trip tests cover thinking signatures, redacted thinking and server tools.
- **Spec style.** Specs follow the Hoist testing doc: real test app, `hoistCore.route` with streaming `Response`s, no `vi.mock`, a protective header comment, behavior-named tests.
- **Code hygiene.** No em dashes, no comments about history, consistent section dividers, `null` sentinels, lodash where it helps.
