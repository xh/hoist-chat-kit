## Waiting for John

- For demos: the throwaway H2 server's app timezone is UTC, so after 19:00 New York time "today"
  is tomorrow, and the orders for today are nearly empty, by design. Today's orders are also empty
  early in the morning, before any order time has passed. A demo should either set Toolbox's app
  timezone to `America/New_York` and run in market hours, or pick an earlier as-of date.
- Toolbox's docs on throwaway servers run by agents should say to set
  `APP_TOOLBOX_MULTI_INSTANCE_ENABLED=false`. Multi-instance is on by default in development, so a
  second throwaway server silently joins the shared server's Hazelcast cluster. `blueprints-data`
  did this for about seven minutes, with no harm done.
- Toolbox has an older bug, outside the slice: `portfolio/closingPriceHistory?daysBack=30` returns
  a 500, because `PortfolioController` casts a String to an int. The client never passes
  `daysBack`. `blueprints-data` left it alone.
- Sessions need John's approval for `git commit` in their own sessions. `blueprints-ck` keeps
  its work staged in logical chunks until then.
