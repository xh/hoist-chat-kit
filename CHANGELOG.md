# Changelog

## 1.0.0-SNAPSHOT - unreleased

The first release of Hoist Chat Kit, a library of chat components for Hoist React applications.
It holds a conversation engine, transports and codecs for common backends, generative UI built on
Hoist components, a thread layer, and the desktop chat components. See the
[docs index](docs/README.md) for each package.

Requires `@xh/hoist` v89 or later.
